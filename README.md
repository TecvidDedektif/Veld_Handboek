# Veldhandboek

Persoonlijk veldhandboek: meten en storingzoeken in de telemetrie.

Site: https://tecviddedektif.github.io/Veld_Handboek/

## Opbouw

- `index.html` – overzicht met zoekveld
- `procedures/` – één pagina per procedure of praktijkgeval
- `tools/` – hulpmiddelen, zoals de mA ↔ debiet rekenmachine
- `assets/zoek.js` – lijst van alle pagina's voor het zoekveld (nieuwe pagina = hier een regel toevoegen)
