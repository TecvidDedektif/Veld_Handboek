UFC 400 uitlezen met KMS en PACTware

Parameters, diagnose en een signaalsnapshot van een KROHNE UFC 400 vastleggen, bijvoorbeeld bij demin-meters.

Wat je nodig hebt

HardwareSoftware
KROHNE USB-GDC-adapterKROHNE Monitoring Software (KMS)
USB naar mini-USB kabelPACTware 6.1 met de UFC 400 DTM

Test vóór vertrek. Controleer op een testopstelling met een UFC 400 dat de laptop, de adapter en de software werken. Dan weet je ook al waar alles zit.

Kısaca (Türkçe)

Gerekenler: KROHNE USB-GDC adaptörü, mini USB kablo, KMS ve PACTware 6.1. Yola çıkmadan önce test düzeneğinde laptopu ve yazılımı dene.

Deel 1: KROHNE Monitoring Software

  1. Aansluiten

    Haal het display voorzichtig uit de houder. Sluit de mini-USB kabel aan op de aansluiting op de flowmeter.

  2. Verbinden

    Open KMS. Device → Connect (of F8).

    Communication Interface op COM port. Kies de juiste COM-poort: die zie je in Windows Apparaatbeheer. OK.

  3. Parameters exporteren

    Reporting → Parameters → Export → Export to CSV… → Select All → Export. Sla op met het opslaan-icoon.

  4. Diagnose opslaan

    Achter elkaar openen en telkens opslaan met het opslaan-icoon:

    • Diagnostics
    • Diagnostics 2
    • Volume Flow

  5. Signaalsnapshot

    View → Signal Snapshots…. Zet Repetition Mode op Single Shot en klik Snapshot.

    Als het beeld verschijnt: Log to .CSV file en opslaan.

  6. Afsluiten

    Device → Disconnect. Sluit KMS af.

Kısaca (Türkçe)
  1. Ekranı yuvasından çıkar, mini USB'yi tak.
  2. KMS: Device → Connect, COM portunu Aygıt Yöneticisi'nden bul.
  3. Reporting → Parameters → CSV olarak dışa aktar (Select All).
  4. Diagnostics, Diagnostics 2 ve Volume Flow'u ayrı ayrı kaydet.
  5. View → Signal Snapshots: Single Shot, Snapshot, CSV'ye kaydet.
  6. Device → Disconnect.

Deel 2: PACTware

  1. Project opbouwen

    Open PACTware 6.1 en maak een New Project. Klik op het + bij de COM DTM en kies de GDC-adapter. Controleer de gegevens, OK.

    Klik daarna op het + om de UFC 400 eronder te zetten.

  2. Verbinden

    Klik op de drie puntjes van de USB-adapter → Connect. Daarna de drie puntjes van de UFC 400 → Connect.

    In de projectboom staan nu de adapter en de UFC 400, allebei verbonden.

  3. Gegevens uit het apparaat laden

    Rechtermuisklik op de UFC 400 → Load from Device.

    Deze stap niet overslaanZonder Load from Device kijk je naar de standaardwaarden van de DTM, niet naar de echte instellingen. Een leeg serienummer of tekst als „HART MESSAGE” verraadt dat.

  4. Meetwaarden vastleggen

    Dubbelklik op de UFC 400 → Measurement → Cyclic update. Maak een schermafbeelding met Windows + Shift + S en sla die op.

  5. Afsluiten

    Disconnect. Display terug in de houder.

Kısaca (Türkçe)
  1. PACTware'de yeni proje: önce GDC adaptörü, altına UFC 400.
  2. Önce adaptöre, sonra UFC 400'e Connect.
  3. Load from Device yap. Bunu atlarsan gerçek ayarları değil, varsayılan değerleri görürsün.
  4. Measurement → Cyclic update, Windows + Shift + S ile ekran görüntüsü al.
  5. Disconnect, ekranı yerine tak.
